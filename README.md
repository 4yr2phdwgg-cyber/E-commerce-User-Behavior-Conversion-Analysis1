# 美妆电商用户行为与转化分析项目报告
**E-commerce User Behavior & Conversion Analysis**

## 一、项目背景

本项目基于 REES46 美妆电商用户行为数据集，通过 Python、Pandas 等工具对用户浏览、加购、移除购物车和购买行为进行清洗、统计与分析。

项目主要围绕用户行为特征、购买转化情况、月度经营表现以及商品和品牌销售表现展开，希望从用户行为数据中发现转化过程中的问题，并为电商平台的运营决策提供数据参考。

### 分析目标

1. 了解用户整体行为规模及不同事件的分布情况。
2. 分析用户从浏览到购买的转化过程，识别主要流失环节。
3. 对比不同月份的用户行为和购买转化表现。
4. 识别销售额和销量表现突出的商品及品牌。

## 二、数据来源与字段说明

### 2.1 数据来源

- 数据集：E-commerce Events History in Cosmetics Shop
- 数据来源：REES46
- 数据时间范围：2019年10月至2020年2月
- 原始数据总量：18,208,129行

### 2.2 主要字段

| 字段 | 含义 |
|---|---|
| event_time | 用户行为发生时间 |
| event_type | 用户行为类型 |
| product_id | 商品ID |
| category_id | 品类ID |
| category_code | 品类编码 |
| brand | 品牌 |
| price | 商品价格 |
| user_id | 用户ID |
| user_session | 用户会话ID |

其中，`event_type` 包含四种行为：

- view：浏览商品
- cart：加入购物车
- remove_from_cart：从购物车移除商品
- purchase：购买商品

## 三、数据清洗与预处理

### 3.1 缺失值处理

原始数据缺失情况如下：

| 字段 | 缺失数量 |
|---|---:|
| event_time | 0 |
| event_type | 0 |
| product_id | 0 |
| category_id | 0 |
| category_code | 17,894,638 |
| brand | 7,685,089 |
| price | 0 |
| user_id | 0 |
| user_session | 4,047 |

处理方式：

1. 删除缺少 `user_session` 的记录，避免影响会话级行为分析。
2. 将缺失的 `brand` 填充为 `unknown`，保留原始行为记录。
3. 将缺失的 `category_code` 填充为 `unknown`。
4. 将 `event_time` 转换为日期时间格式。
5. 检查并处理重复记录。

由于 `category_code` 缺失比例较高，本项目不将其作为主要分析维度。

### 3.2 异常价格处理

对价格为零和负数的记录进行检查：

- 负价格记录出现在 purchase 事件中。
- 零价格记录出现在 view、cart 和 remove_from_cart 事件中。

考虑到缺少退款、赠品等业务标识，项目保留这些记录，不直接将其认定为退款或赠品。

后续购买金额采用 purchase 事件中的 `price` 汇总，并保留负价格记录。因此，该指标属于数据集内的购买事件金额统计，不等同于经过财务核算的实际营业收入。

### 3.3 分析数据规模

清洗及预处理后，实际参与统计的事件数量为 **17,223,047条**。

| 指标 | 数量 |
|---|---:|
| 用户数 | 1,448,926 |
| 会话数 | 3,937,328 |
| 事件数 | 17,223,047 |

## 四、用户整体行为分析

### 4.1 事件类型分布

| 行为类型 | 事件数量 | 事件占比 |
|---|---:|---:|
| view | 8,426,680 | 48.93% |
| cart | 5,017,696 | 29.13% |
| remove_from_cart | 2,643,030 | 15.35% |
| purchase | 1,135,641 | 6.59% |
| **合计** | **17,223,047** | **100%** |

主要发现：

1. 浏览事件占比最高，达到48.93%，说明浏览是平台最主要的用户行为。
2. 加购事件占29.13%，表明用户在浏览后有一定比例会产生进一步的购买意向行为。
3. 移除购物车事件占15.35%，说明购物车中的商品存在一定程度的取消或移除行为。
4. 购买事件占全部行为的6.59%。

需要注意，事件占比反映的是不同类型事件在全部行为记录中的构成，不代表用户转化率。一个用户可能产生多条浏览、加购或购买事件。

## 五、用户转化漏斗分析

本项目使用两种口径分析用户从浏览到购买的转化情况。

### 5.1 简易漏斗分析

简易漏斗按照不同事件的会话数量进行统计，再计算相邻环节之间的比例。

| 转化环节 | 转化率 | 流失率 |
|---|---:|---:|
| 浏览 → 加购 | 23.40% | 76.60% |
| 加购 → 购买 | 15.49% | 84.51% |
| 浏览 → 购买 | 3.62% | 96.38% |

主要发现：

- 浏览到加购的转化率为23.40%。
- 加购到购买的转化率为15.49%。
- 浏览到购买的整体转化率为3.62%。

该口径统计的是发生过相应行为的会话，不严格要求行为发生的先后顺序，因此更适合观察行为覆盖情况。

### 5.2 严格顺序漏斗分析

为了更准确地观察用户行为路径，本项目进一步按照会话进行分析，比较每个会话中首次浏览、首次加购和首次购买的时间。

仅当首次加购发生在首次浏览之后，才计入浏览到加购环节；首次购买发生在首次加购之后，才计入加购到购买环节。

分析结果：

| 转化环节 | 转化率 | 流失率 |
|---|---:|---:|
| 浏览 → 加购 | 13.99% | 86.01% |
| 加购 → 购买 | 11.83% | 88.17% |
| 浏览 → 购买 | 1.65% | 98.35% |

主要发现：

1. 严格顺序下，浏览到加购的转化率为13.99%，明显低于简易漏斗的23.40%。
2. 加购到购买的转化率为11.83%，说明加购行为并不必然带来购买。
3. 浏览到购买的整体转化率仅为1.65%，从浏览到最终购买的过程中存在较大流失。

**分析结论：** 严格顺序漏斗更适合描述会话中的行为先后关系。对于电商运营而言，可以重点关注浏览到加购以及加购到购买两个阶段，进一步研究商品展示、价格、库存、促销和结算体验等因素。

需要说明的是，该漏斗按照会话内各类事件的首次发生时间判断，没有进一步要求这些事件属于同一个商品，因此不能将其解释为严格的单商品购买路径。

## 六、月度经营表现分析

### 6.1 月度核心指标

| 月份 | 购买金额 | 活跃用户数 | 会话数 |
|---|---:|---:|---:|
| 2019-10 | 1,211,538.43 | 399,634 | 873,960 |
| 2019-11 | 1,531,016.90 | 368,183 | 942,022 |
| 2019-12 | 299,858.01 | 117,896 | 238,530 |
| 2020-01 | 1,321,535.48 | 410,018 | 965,351 |
| 2020-02 | 1,206,289.21 | 391,005 | 931,668 |

五个月购买事件金额合计：

**5,570,238.03**

### 6.2 月度转化率对比

| 月份 | 浏览 → 加购 | 加购 → 购买 | 浏览 → 购买 |
|---|---:|---:|---:|
| 2019-10 | 18.37% | 8.95% | 1.64% |
| 2019-11 | 13.77% | 13.53% | 1.86% |
| 2019-12 | 12.17% | 12.95% | 1.58% |
| 2020-01 | 12.42% | 13.13% | 1.63% |
| 2020-02 | 12.17% | 12.48% | 1.52% |

主要发现：

**1. 2019年11月的整体购买转化表现最好。**

11月浏览到购买的转化率达到1.86%，高于其他月份。

**2. 2019年10月的浏览到加购转化率最高。**

10月浏览到加购转化率为18.37%，但加购到购买转化率只有8.95%。说明较高的加购比例并不一定意味着更高的最终购买转化。

**3. 2020年1月和2月的转化率相对接近。**

两个月浏览到购买的转化率分别为1.63%和1.52%，整体变化不大。

### 6.3 数据时间范围限制

2019年12月的数据覆盖不完整：

- 第一次浏览：2019-12-01 00:00:00 UTC
- 最后一次浏览：2019-12-09 09:12:21 UTC

因此，12月数据仅覆盖约8天多。

这意味着12月的购买金额、活跃用户数和会话数明显受到观察时间范围影响，不能直接与完整月份进行总量比较。

本项目保留12月数据用于整体统计和月度转化率参考，但在解释月度经营规模时需要特别注明这一限制。

## 九、项目总结与业务建议

通过本项目的分析，可以得到以下结论：

1. 平台用户行为以浏览为主，购买事件仅占全部事件的6.59%。
2. 严格顺序漏斗下，浏览到购买的转化率为1.65%，用户在浏览、加购和购买过程中存在明显流失。
3. 2019年11月的浏览到购买转化率最高，达到1.86%；2019年10月虽然浏览到加购表现较好，但加购到购买的转化表现较弱。
4. 商品销售额与销量排名存在差异，部分商品依靠较高的购买事件数量贡献销售额，部分商品则表现为销售额较高但购买事件数量相对较少。
5. 品牌runail在销售额和销量两个指标中均表现突出。

基于以上发现，可以提出以下运营建议：

- 优化商品详情页和商品展示方式，提升浏览到加购的转化。
- 分析加购后未购买的原因，重点关注价格、库存、促销及结算流程。
- 对高销售额和高销量商品进行重点监测，制定差异化商品运营策略。
- 关注销售额与销量排名差异较大的商品及品牌，进一步研究其价格和产品结构。

以上建议属于基于现有数据的分析方向，具体效果仍需通过进一步的数据验证或运营实验确认。

## 十、项目局限性

1. **数据时间不完整：** 2019年12月只覆盖约8天多，影响月度规模对比。
2. **品牌字段缺失：** purchase事件中约42.61%的品牌信息缺失，品牌排名仅代表已知品牌记录。
3. **品类字段问题：** `category_code` 缺失比例很高，且商品与品类ID之间存在不一致情况，因此未将品类作为核心分析维度。
4. **缺少订单ID：** purchase事件记录数不能直接等同于实际订单数，购买事件金额也不能直接等同于财务确认收入。
5. **缺少成本数据：** 无法计算商品和品牌的利润、毛利率。
6. **缺少渠道及营销数据：** 无法分析不同获客渠道的转化表现、获客成本和广告投资回报率。
7. **用户身份验证有限：** 本项目未验证匿名用户ID在跨月份范围内的身份稳定性，因此不对用户留存和复购情况作确定性业务判断。
